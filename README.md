# Западный радар

Каждые 10 минут проверяет страницы правил Anthropic / OpenAI / Gemini, обновления сайтов anthropic.com и support.claude.com, блоги ИИ-компаний, западные техСМИ, Google News и Hacker News. Новое и важное сразу отправляет в Telegram-канал.

- 🔴 — изменились правила, списки стран, ограничения для России, баны аккаунтов.
- 🟡 — официальные анонсы, новые модели, цены и тарифы у ИИ-сервисов.

Если сообщений нет, значит, важного не было.

Настройки: Settings → Secrets and variables → Actions → `TG_BOT_TOKEN`, `TG_CHAT_ID`.
Ручной запуск: Actions → radar → Run workflow.
Память радара (снимки страниц и что уже отправлено) хранится в папке `state/`.
